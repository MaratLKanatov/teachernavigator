# Цифровой навигатор учителя

Минималистичный статический справочник с тремя уровнями навигации: главная страница → модуль → цифровой инструмент. Сайт работает без сервера приложений, базы данных, сборки и сторонних библиотек. Его можно разместить на обычном статическом хостинге или открыть `index.html` в браузере.

## Структура проекта

```text
index.html              главная HTML-оболочка
css/styles.css          единые стили и адаптивная вёрстка
js/app.js               навигация, шаблоны страниц, пустые состояния
 data/
   modules.js            каталог модулей
   tools.js              каталог цифровых инструментов
   examples.js           примеры и готовые материалы
 assets/                 папка для локальных файлов и материалов
```

## Как добавить модуль

Откройте `data/modules.js` и добавьте объект в массив `window.NAVIGATOR_DATA.modules`:

```js
window.NAVIGATOR_DATA.modules = [
  {
    id: "assessment",
    name: "Оценивание и обратная связь",
    description: "Цифровые инструменты для оценивания и обратной связи."
  }
];
```

`id` должен быть уникальным. Для надёжных URL используйте латинские буквы, цифры и дефисы; не меняйте ID без необходимости, если на него уже ссылаются инструменты. Если модулей несколько, перечислите объекты через запятую.

## Как добавить цифровой инструмент

Откройте `data/tools.js` и добавьте объект. Значение `moduleId` должно совпадать с `id` одного из модулей.

```js
window.NAVIGATOR_DATA.tools = [
  {
    id: "sample-tool",
    moduleId: "assessment",
    name: "Название цифрового инструмента",
    description: "Краткое пояснение назначения инструмента.",
    pedagogicalTasks: "Педагогические задачи, которые помогает решать инструмент.",
    officialUrl: "https://example.com",
    steps: [
      {
        title: "Подготовка",
        description: "Описание первого шага."
      },
      {
        title: "Создание материала",
        description: "Описание следующего шага."
      }
    ],
    resultCheck: "Рекомендации по проверке результата."
  }
];
```

Это только пример структуры для владельца проекта — данные в каталоге сайта изначально пусты. Удалите примерный объект из этого фрагмента, если не хотите его использовать. Чтобы добавить несколько записей, добавьте несколько объектов в массив. У каждого инструмента должен быть уникальный `id`.

## Как добавить пример или готовый материал

Откройте `data/examples.js` и добавьте объект в массив `window.NAVIGATOR_DATA.examples`. Поле `toolId` связывает материал с инструментом.

```js
window.NAVIGATOR_DATA.examples = [
  {
    id: "sample-resource",
    toolId: "sample-tool",
    title: "Название материала",
    description: "Краткое описание материала.",
    type: "Документ",
    url: "assets/material.pdf"
  }
];
```

В `url` можно указать официальный внешний адрес (`https://…`) или путь к файлу внутри проекта, например `assets/material.pdf`. Положите локальный файл в папку `assets`. Чтобы добавить несколько материалов, добавьте ещё объекты с уникальными `id`.

## Редактирование и удаление

- Чтобы изменить текст, отредактируйте соответствующее поле в нужном файле `data/*.js`.
- Чтобы удалить запись, удалите её объект из массива.
- При удалении модуля удалите также связанные инструменты и материалы либо обновите их `moduleId` / `toolId`.
- Для пустых массивов сайт автоматически показывает аккуратные сообщения; менять шаблоны или стили не требуется.
- В интерфейсе не отображаются незаполненные поля как технические подсказки.

## Адреса страниц

Страницы используют адресуемые параметры URL, поэтому они работают при прямом открытии и обновлении:

- Главная: `index.html`
- Модуль: `index.html?page=module&id=assessment`
- Инструмент: `index.html?page=tool&id=sample-tool`

Идентификаторы в примерах выше показывают принцип формирования адресов, а не добавленные в стартовый каталог записи. Несуществующие ID открывают страницу «Страница не найдена».

## Публикация

Загрузите содержимое папки `digital-navigator` на статический хостинг, сохраняя структуру папок. Серверная часть не нужна. Для проверки локально можно открыть `index.html`; все данные загружаются из локальных JavaScript-файлов без `fetch` и без сторонних зависимостей.
