# Цифровой навигатор учителя

Статичный адаптивный сайт на HTML, CSS и небольшом JavaScript.

## Просмотр
Откройте `index.html` в современном браузере.

## Реализованные страницы
- `index.html` — главная страница.
- `modules/lesson-design.html` — модуль 1 «Проектирование урока».
- `assets/css/style.css` — общие стили.
- `assets/css/module.css` — стили страницы модуля.
- `assets/js/main.js` — мобильное меню.

## Следующие страницы
Ссылки на страницы модулей 2 и 3, методическую основу и подробные карточки инструментов уже предусмотрены, но сами страницы ещё предстоит создать.

Шрифт Manrope загружается из Google Fonts при наличии подключения к интернету; без интернета используется системный шрифт.
